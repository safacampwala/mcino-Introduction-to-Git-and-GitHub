# Simple Interest Calculator

This project is a simple Bash script-based calculator that computes 
simple interest based on user input.

## Description
The calculator takes the following inputs from the user:
- Principal Amount
- Rate of Interest
- Time Period

It then calculates and displays the simple interest using the formula:

Simple Interest = (Principal × Rate × Time) / 100

## Usage
Run the script `simple-interest.sh` in a Bash terminal and enter the 
required values when prompted (Principal, Rate of Interest, and Time Period).
